A deadpan one-star review of gravity, the everyday essential that never
takes a day off — especially not the day your phone slips out of your hand.
One line, 80 characters, no exclamation marks, no winking. A real complaint
filed in earnest against a thing that cannot be fixed.

## Run

```sh
python3 main.py
```

This writes the review to `output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The file holds
exactly one line of UTF-8 text with no trailing newline.
